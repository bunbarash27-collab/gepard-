# TAXI OS — помощник таксиста (v1)

Android-приложение, которое показывает водителю **реальный** заработок: не оборот, а чистыми после топлива, амортизации и комиссии.

## Что умеет v1

- **Сегодня** — выручка, расходы, чистыми, время работы, доход/час, цель дня с прогрессом; старт/завершение смены, заказ в одно касание (км и минуты по GPS, вводится только сумма), пауза (обед, отдых — время и пробег не считаются), ручной ввод как запасной вариант.
- **GPS-трекинг смены** — foreground-сервис считает общий пробег за смену; его можно поправить по одометру (во время смены или при закрытии). Бензин и амортизация считаются от этого пробега; на паузе ничего не считается.
- **Автоматика по Яндекс Про** — при доступе к уведомлениям статусы Яндекс Про ведут смену сами: «На линии» начинает смену, «На заказе» открывает заказ, «На линии» закрывает его (км и минуты по GPS, остаётся вписать сумму), «Занят» ставит паузу. Отключается в настройках. Все уведомления складываются в «Журнал уведомлений».
- **Экран Яндекс Про** — опциональная служба специальных возможностей читает стоимость с экрана поездки («Стоимость поездки с учетом пробок»), экранов «Оплачено картой» / «Получите наличными» и списка «Детализация» (суммы сопоставляются с заказами по времени). Заказ без экрана поездки считается отменённым и не записывается.
- **Заказ** — калькулятор «брать / не брать»: вводите цену, километры и минуты, получаете прогноз чистыми, ₽/час и вердикт 🟢/🟡/🔴 с учётом холостого возврата.
- **Статистика** — итоги за 7/30 дней или всё время, доход/час по часам суток, автоматические выводы («лучшее время 07:00–10:00», «после 21:00 доход падает на N%», доля холостого пробега), список смен.
- **Настройки** — расход л/100 км, цена топлива, амортизация ₽/км, комиссия %, процент холостого возврата, целевой доход/час, цель дня.

Все данные хранятся локально на телефоне (Room/DataStore), интернет и регистрация не нужны. Минимальная версия Android — 8.0 (API 26).

Разрешения: геолокация (точная) и уведомления — для трекинга смены; доступ к уведомлениям и специальные возможности — опционально, для автоматики Яндекс Про.

## Формулы

- Топливо = км × расход / 100 × цена литра
- Амортизация = км × ₽/км
- Комиссия = выручка × %
- Чистыми = выручка − комиссия − топливо − амортизация − прочие расходы (топливо и амортизация — от общего пробега смены)
- Оценка заказа: к дистанции и времени заказа добавляется холостой возврат (по умолчанию 50 %); вердикт «брать», если ₽/час ≥ целевого, «на грани» — от 70 % целевого, иначе «невыгодно».

## Сборка

Требуется JDK 17 и Android SDK (platform 35, build-tools 35).

```bash
./gradlew testDebugUnitTest assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Стек: Kotlin, Jetpack Compose (Material 3), Room, DataStore, Navigation Compose.
